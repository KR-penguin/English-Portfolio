### 1️⃣ Learn Up!
#### 🎮 Overview
- Genre: AI-powered Game-based Learning Platform
- Platform: Mobile (Android - Currently in OBT)
- Engine: Godot (Client) | NestJS, ExpressJS (Server)
- Role: Founder, PD, Lead Engineer (Directed planning, architecture design, and full-stack development)
- Link: https://play.google.com/store/apps/details?id=com.nplus.learnup&pli=1

#### 💥 Problem
- Decreased reliability of educational content due to LLM hallucinations and context loss.
- The hint system merely provided answers rather than stimulating thought; a 'Socratic method' of questioning was not structurally implemented.
- Information loss during summarization and key concept extraction, leading to a lack of discrimination for exam preparation.
- Lack of customized problem-generation features.

#### 🛠️ Solution
- Introduced a paragraph-based data parsing strategy to maintain context and maximize information extraction accuracy.
- Improved the single Monolithic API structure into a **pipeline structure based on layer-specific separation of responsibilities**, securing processing speed and data consistency.
- Directly integrated **Bloom's Taxonomy (6 stages)** and **Socratic questioning** algorithms into prompt engineering and server logic.
- Built a 'Thinking Steps' control feature considering the learner's cognitive load, alongside a 16-language localization engine.

#### 📈 Result
- Significantly increased learner satisfaction and educational effectiveness by generating high-quality problems based on Bloom's 6 stages.
- Increased learning efficiency through an 'interactive hint system' that guides users to find answers themselves rather than just giving them away.
- Optimized problem generation wait times and improved summary data precision through asynchronous pipeline processing.
- Secured global scalability and eliminated market entry barriers by stabilizing the 16-country localization engine.

#### 🎮 Overview
- Genre: Strategy-based Hacking Game
- Platform: PC
- Role: Server Logic Refactoring, CRUD Design, Client-Server Boundary Structure Improvement

#### 🏆 Awards

#### 💥 Problem
- Game rules, request processing, and business logic were mixed within the server code.
- Increased maintenance costs when adding or modifying features.
